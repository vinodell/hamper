# Цена при полной оплате и интерактив Ойнелово

Начальная точка: `84b3ae821637c243d6a94ccb467ea64e28199e0b`.
Изменения подготовлены для ревью владельцем; коммит, push и публикация требуют
его отдельного явного подтверждения.

## Поведение

- Администратор задаёт необязательную цену **При 100% оплате** при создании
  участка или рядом с базовой ценой существующего участка. Значение —
  положительное число с точностью до двух знаков, строго ниже базовой цены.
- Если поле заполнено, таблица, списки, popup и tooltip карты показывают
  зачёркнутую базовую и актуальную цену в одной строке, а под ними — наклейку
  **При 100% оплате**.
  Пустое поле отключает всё специальное оформление; отображается только базовая
  цена. Цена не рассчитывается из процента общей акции.
- Сортировка по цене и минимальная цена проекта учитывают сохранённую цену
  полной оплаты. У минимальной цены указано условие оплаты, если оно требуется.
- Изменение и очистка цены распространяются между вкладками, открытая карточка
  принимает подтверждённые данные. Несохранённая цена переживает повторный вход.
- FAQ плавно раскрывается и закрывается, включая поворот значка плюса.
  Кнопки доступны с клавиатуры; закрытые ответы скрыты от фокуса и скринридера.
- Проданные участки и легенда карты имеют цвет `#c9303e`. У заливки участков
  прозрачность совпадает с забронированными: alpha 55% в Ойнелово и 50% в
  стандартной теме карты. Выбор проданного участка остаётся недоступным.
- Кнопки, галерея, список участков и карта Ойнелово дают сдержанный визуальный
  отклик. Hover ограничен устройствами с точным указателем; reduced motion
  отключает движения. Новые библиотеки анимации не добавляются.

## Данные и обновление

API поле `fullPaymentPrice` — строка с ценой либо `null`. Админка отправляет
пустую строку для очистки. Старые ответы без поля читаются как `null`; старые
PUT без нового поля сохраняют уже установленное значение. Массовые изменения
проверяются и сохраняются атомарно.

Миграция `0002_full_payment_price.sql` добавляет nullable колонку
`full_payment_price` без изменения цен и без удаления участков. Перед публикацией
Worker миграция выполняется существующим workflow. Production данные в ходе
разработки и проверок не изменяются.
